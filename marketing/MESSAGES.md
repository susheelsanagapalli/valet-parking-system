Tips:
- Post reels with the caption's first line visible ("Still using paper valet tickets?"); it is the hook.
- On WhatsApp, send the video as a file (📎 → Document) if the recipient needs full quality; normal sends are compressed.
- All videos have voice-over; the showcase also has background music. Captions on screen make them work with the sound off too.
